## 2026 Q3

- **New Content: [Building an agentic engineering system on GitHub](../governance/recommendations/agentic-engineering-system-on-github)** - Published a design guide that maps the moving parts of an agentic engineering system to GitHub primitives, covering the governance and shared knowledge stocks, the define, deliver, and detect activities, and the patterns and anti-patterns teams encounter when combining them
- **New Content: [Agentic governance taxonomy](../governance/recommendations/agentic-governance-taxonomy)** - Published an inventory framework that decomposes agent governance into five sub-categories - identity and access, authorization boundaries, automated assurance controls, audit and provenance, and policy definition and distribution - so enterprises can assess, configure, and audit each area independently
- **New Content: [Shared knowledge for agentic engineering](../governance/recommendations/agentic-shared-knowledge)** - Published a taxonomy for inventorying and improving the context an engineering system holds, explaining why agent output quality is bounded by available context and how code, decision, signal, customer, and agent memory context each support the work
- **Update: [Adopting GitHub Copilot at scale](../productivity/recommendations/adopting-copilot-at-scale)** - Corrected Copilot metrics and quickstart references and aligned vertical classifications with the canonical taxonomy to keep adoption guidance accurate
- **New Content: [Recommendations for effective continuous integration (CI)](../productivity/recommendations/effective-ci)** - Published guidance for building CI that teams can trust, covering fast feedback, test design, pull request signals, caching, and approaches for scaling CI
- **New Content: [Building resilient CI/CD with GitHub Actions](../architecture/recommendations/designing-resilient-ci-cd)** - Published guidance for maintaining deployment continuity during CI/CD outages, including portable deployment logic, independent authentication, and a rehearsed recovery path
- **New Content: [Building resilience with repository mirroring](../architecture/recommendations/building-resilience-with-repository-mirroring)** - Published a practical approach to keeping critical services deployable from an independent repository mirror, with guidance for preparation, testing, and recovery
- **Update: [Managing AI credits](../governance/recommendations/managing-ai-credits)** - Expanded AI credit governance guidance with budget scopes and evaluation order, and practices to help prevent exhaustion of shared credit pools
